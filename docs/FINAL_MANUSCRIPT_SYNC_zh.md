# 最终论文源码与仓库对齐

本次依据最终 LaTeX 工程 `bibm_arivx.zip` 内的 `main.tex`，不修改论文。
来源校验值和七位作者顺序见
[final_manuscript_manifest.json](../results/final_manuscript_manifest.json)。

压缩包自带的 `main.pdf` 仍是六位作者；当前源码是七位作者，第三位为 Xuanlyu Zhu。
本次已从未修改的源码重新编译，并按源码更新仓库引用，不沿用旧 PDF 的名单。
新编译 PDF 仅留在本地忽略目录，不作为仓库文件发布。

README 展示最终源码的图一和图二。图一直接复制原 PNG；图二来自当前源码实际排版的
三栏提示词，不使用源码已注释掉的旧 `figures/image2.png`。

图二与代码原先存在三处实质差异：规则整理未要求完整 schema；工具合成固定返回
`N/A`；抽取额外要求计算平均动脉压并填充不支持的非空字段。现已按图二调整，
三个主阶段共用 [prompts.py](../src/toolmed_agent/prompts.py)。
图二本身是概括，运行时仍须填入具体规则、schema、三个示例和当前病例。
[PROMPTS.md](PROMPTS.md) 给出调用关系及适用范围。

工具验证使用每个计算器的 8 个训练样例，随机无放回抽取；同一轮修复过程复用样例。
最多 5 次候选生成对应首次生成加最多 4 次修复，不是 8 次总生成。
按需生成分支已改为只从训练集取样，避免将测试答案用于生成或修复。

仓库仅简要引用论文最终准确率 **86.73%**，不上传旧运行逐例记录、大模型完整回答，
也不发布本次对旧运行的重算汇总。运行者自己的输出保存在忽略目录。
发布检查也会拒绝被强制加入版本控制的原始抽取和完整回答文件。

参数匹配缺陷已修复，最终答案转换口径未改；必要的评测差异和 Case C 笔误集中披露在
[KNOWN_ISSUES.md](../results/KNOWN_ISSUES.md)，不为与论文笔误一致而修改固定基准答案。

55 个冻结工具保持原样。最终 SFT adapter、训练命令、随机种子和精确软件环境尚未提供，
当前仓库不能承诺无需外部材料即可完整复现论文分数。
