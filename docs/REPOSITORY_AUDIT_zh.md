# 论文代码仓库审计

审计日期：2026-10-14。参照 [lingluodlut](https://github.com/lingluodlut) 的公开论文代码仓库，
本仓库的目录组织、安装入口、数据版本、计算工具、示例和结果说明已具备清楚的交付结构。
完整复现投稿的 86.73% 仍缺少最终 SFT 权重、训练及运行记录和原实验环境，不能认定所有复现要求均已满足。

当前论文依据为作者最新提供的 `bibm_arivx.pdf`，共 9 页；文件校验值和原图来源见
[figure1.source.json](../assets/figure1.source.json)。新版已将工具验证样本数改为 8，
与原始生成记录一致，旧稿的“5 个与 8 个验证样本不一致”结论已撤销。

本次保留 86.73% 最终准确率、97.47% 参数匹配率和 94.91% 工具级准确率。
评测函数、四张结果表和 55 个计算器文件未因本次审计而修改。

## 参照仓库与判断依据

下列项目体现了导师相关论文代码仓库的共同做法：明确论文与方法、说明依赖和目录、
提供数据及模型准备方式、给出输入输出示例、解释训练和推理命令。这是对公开仓库的归纳，
不是导师另外颁布的统一评分标准，也不要求照搬历史项目的框架或依赖版本。

## 本次补充与修正

中英文 README 已使用论文原图一；旧的仓库重绘示意图已移除。图像来源、原 PDF 校验值、页码、
尺寸和 PNG 校验值见 [figure1.source.json](../assets/figure1.source.json)，验证脚本也会检查图片。

[输入输出示例](../examples/README.md) 使用 120/80 mmHg 的结构化压力参数，计算平均动脉压
93.33333333333333 mmHg。它只调用冻结计算工具，不需要模型、密钥或基准下载。

工具重建入口原来会直接调用不存在的 `build_rag_docs.py`。现在缺少该材料时会明确提示
`--stage1_docs_jsonl` 所需的准备语料，并保留已有语料的加载方式。
[复现指南](REPRODUCTION.md) 给出相应命令及环境变量说明。

原文档把 `r5` 与“最多四次修复”视作矛盾，这一判断已修正：当前循环中的 `max_rounds`
包含首次生成，五次总轮次最多对应四次后续修复。最新论文第 3-4 页写明八个验证样本和
最多四次后续修复，并不是八次总生成。

原启动脚本设置 `MAX_ROUNDS=5`、`SAMPLE_PER_CALC=8`。55 个计算器的合并生成记录中，
每个计算器的验证样本数均为 8；105 条候选迭代记录的最高轮次为 5，实际执行验证的各轮
复用同一组样本。公开汇总及源记录校验值见
[generation_summary.json](../artifacts/calculators/gpt_5_5/generation_summary.json)。
53 个选择出的工具通过全部训练检查，另外 2 个保留了最佳候选。这个训练验证计数不替代
测试集的 94.91% 工具准确率。

参考配置已对齐五轮总生成、八个验证样本；通用命令入口的默认值与实际实验启动参数可能
不同，复现实验需使用 [REPRODUCTION.md](REPRODUCTION.md) 给出的显式参数。

## 完整复现还需提供的材料

1. 投稿最佳运行所用的最终 SFT adapter、`adapter_config.json`、权重校验值和获取方式。
   应能明确区分早期 85.27% 运行和论文 86.73% 运行。
2. 原始 SFT 训练脚本或完整命令、训练数据版本、随机种子和最佳 checkpoint 的选择依据。
   新版论文已报告 LoRA rank/alpha/dropout=16/32/0.05、学习率 5e-5、5 个 epoch、
   global batch=8 和最大训练序列长度 8192；需要以运行记录确认这些配置对应最佳权重。
3. 投稿运行的 Python、PyTorch、Transformers、PEFT、vLLM、CUDA 精确版本，GPU 型号、
   数量、显存及完整启动命令。此次 CPU 安装环境不能代替 GPU 原实验环境。
4. 最佳运行的逐例预测、抽取参数、工具输出和原口径判定记录，用于核对 954/1100 以及
   5241/5377。获取和发布这些材料时仍需保留基准来源与许可边界。
5. 公开版可按许可和数据范围补充逐轮生成归档。当前已有源记录，生成样本数、迭代上限和
   选择结果已核对并公开为汇总；原始提示与输出暂不随仓库分发。若重新生成工具，应另行
   评测和报告，不能覆盖现有论文结果。
6. 基线和消融运行的原始计数、运行次数与舍入规则。例如 69.46% 无法直接由
   单次整数正确例数除以 1100 再保留两位小数得到，需要确认是否为多次运行平均或中间舍入。
   当前保持论文数值，不据此猜测或修改它。

正式论文链接、作者和引用信息应在确定公开版本时补全。

## 可立即运行的检查

在仓库根目录安装包后执行：

```bash
python scripts/validate_artifacts.py
python -m unittest discover -s tests -v
python scripts/run_calculator.py --input examples/mean_arterial_pressure/input.json
python scripts/download_data.py
python scripts/evaluate_calculators.py
```

最后一个命令的原口径预期结果为 `correct=1044`、`cases=1100`、
`accuracy=0.949091`、`runtime_errors=0`。完整模型推理的外部条件见
[REPRODUCTION.md](REPRODUCTION.md)，保留评测口径的原因见
[KNOWN_ISSUES.md](../results/KNOWN_ISSUES.md)。
